# Python File Organizer
A simple Python tool that automatically organizes files into folders based on their file extensions.

## Features

- Organizes files by file extension
- Creates folders automatically
- Handles files with unknown extensions
- Prevents accidental overwrites
- Shows files that were moved or skipped
- Displays a final summary

## Technologies

- Python
- pathlib
- shutil

## How to Run

1. Make sure Python is installed.
2. Open a terminal in the project folder.
3. Run the program:

```bash
python organizer.py
```


4. Enter the path to the folder you want to organize.
